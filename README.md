# לימוד — חנות קורסים בעברית

פרויקט React + Bootstrap RTL + JavaScript, עם שרת Express, מסד MongoDB, JWT וסיסמאות bcrypt. כל קוד הממשק ב־`src/main.jsx`; כל קוד השרת ב־`server.js`. נתוני הקורסים בלבד נמצאים ב־`data/catalog.json`.

## הרשאות ושמירת מידע

כל פעולות החשבון, הצפייה, הפורום והניהול עוברות דרך Express ונשמרות ב-MongoDB. אורחים יכולים לצפות בקטלוג ולהירשם. כניסה לקורסים, לפורום ולאזור האישי מחייבת חשבון מחובר; מסכי הניהול ונתיבי הניהול מחייבים תפקיד admin. הרשמה ציבורית יוצרת תלמיד בלבד. החשבון הראשוני של המנהל נוצר בפקודת seed.

אין חשבונות סיור או אימות מתוך אחסון הדפדפן. כאשר השרת או המסד אינם זמינים מוצגת שגיאה. תגובת 401 מבטלת את מצב ההתחברות בממשק ומחייבת כניסה מחדש.

## עדכון התקנה קיימת

שמרו את קובץ .env הקיים ואת מסד הנתונים שלכם. העתיקו את src/main.jsx, server.js, README.md ואת תיקיית data מהגרסה החדשה. מחקו את public/catalog.json הישן ואת תיקיית dist הישנה, ואז הריצו npm run build והפעילו מחדש את השרת והממשק. אין צורך להריץ seed מחדש או למחוק משתמשים והתקדמות. תיקיית data משמשת רק לאתחול מסד חדש.

## דרישות

- Node.js 22 LTS או גרסת LTS תואמת חדשה יותר, עם npm.
- MongoDB Community מקומי פועל, או MongoDB Atlas עם משתמש מסד והרשאת רשת לשרת.
- אינטרנט להפעלת סרטוני YouTube ולטעינת הגופן.
- VS Code מומלץ.

## התקנה והרצה מקומית

1. פתחו את תיקיית הפרויקט ב־VS Code.
2. בטרמינל הריצו `npm ci`.
3. העתיקו את `.env.example` לקובץ `.env` בשורש הפרויקט.
4. החיבור המקומי מוכן כברירת מחדל: `mongodb://127.0.0.1:27017/limud_academy`. אפשר להשאיר את `MONGODB_URI` כפי שהוא בדוגמה, או לשנות אותו אם MongoDB המקומי מאזין בפורט אחר.
5. צרו סוד JWT אקראי באמצעות `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"` ושמרו אותו ב־`JWT_SECRET`.
6. הגדירו `ADMIN_EMAIL`, `ADMIN_PASSWORD` (לפחות 10 תווים ועד 72 בתים), ו־`ADMIN_NAME`. אין סיסמת מנהל קבועה בקוד.
7. הריצו `npm run seed`. הפעולה יוצרת את הקורסים, נושאי הפורום והמנהל הראשוני. הרצה חוזרת אינה דורסת רשומות קיימות.
8. ודאו ששירות MongoDB המקומי פועל, ואז בטרמינל הראשון הריצו `npm start` — שרת API בפורט 4000.
9. בטרמינל השני הריצו `npm run dev` — כתובת Vite תופיע בטרמינל, בדרך כלל `http://localhost:5173`.
10. ודאו ש־`CLIENT_ORIGIN` תואם בדיוק לכתובת הממשק (כולל הפורט). ברירת המחדל בקובץ הדוגמה היא `http://localhost:5173`.
11. היכנסו כמנהל עם הפרטים שהגדרתם, או רשמו חשבון תלמיד חדש.

הסדר המומלץ להרצה הוא:

```text
MongoDB Community  →  npm start (Express)  →  npm run dev (React/Vite)
```

ב־Windows אפשר לבדוק את המסד באמצעות `mongosh "mongodb://127.0.0.1:27017/limud_academy"`. אם הפקודה אינה זמינה, יש להתקין את MongoDB Community ולהפעיל את שירות MongoDB לפני `npm start`.

לאחר יצירת המנהל ניתן להסיר את `ADMIN_PASSWORD` מקובץ הסביבה. שינוי סיסמה מתבצע במסך הפרופיל. שינוי סיסמה ויציאה מבטלים את כל הטוקנים הישנים של המשתמש.

## בנייה והרצה של תוצר הייצור

`npm run build` יוצר את `dist`. שרת Express מגיש גם תיקייה זו. בהרצה מקומית של תוצר הבנייה דרך `http://localhost:4000`, עדכנו `CLIENT_ORIGIN=http://localhost:4000` והשאירו `NODE_ENV=development` כדי לאפשר Cookie על HTTP מקומי.

לפרסום אמיתי יש להגדיר `NODE_ENV=production`, HTTPS, סוד JWT בטוח, חיבור MongoDB והרשאות רשת מצומצמות. `CLIENT_ORIGIN` חייב להיות כתובת הממשק המורשית. אין לפרסם `.env` או סיסמאות.

### ממשק ב־Sites ושרת נפרד

- שרת Express צריך אירוח Node.js מתמשך. הפרסום הסטטי ב־Sites אינו מריץ את `server.js`.
- הגדירו `VITE_API_BASE=https://api.your-domain.example` לפני בניית הממשק, ואת `CLIENT_ORIGIN` בשרת לכתובת הממשק המדויקת.
- מומלץ שהממשק וה־API יהיו תחת אותו אתר, למשל `learn.example.com` ו־`api.example.com`, או להשתמש ב־reverse proxy תחת אותו מקור. ה־Cookie הוא SameSite=Lax; אין להסתמך על Cookie צד שלישי בין דומיינים בלתי קשורים.
- `VITE_API_BASE` הוא משתנה ציבורי של כתובת בלבד. לעולם אין לשים `MONGODB_URI`, סוד JWT או סיסמאות במשתנה שמתחיל ב־VITE.
- נתוני האתחול המלאים נמצאים בתיקיית data מחוץ לתוכן הציבורי. מזהי הסרטונים נמסרים דרך API רק למשתמש מורשה.

## צפייה והשלמה

- השיעור הראשון פתוח; יתר השיעורים דורשים השלמת כל הקודמים. מנהל יכול לצפות לצורך ביקורת.
- הנגן שולח זמן נוכחי ומצב ניגון. השרת צובר מקטעים עם בדיקת הזמן שחלף; קפיצה גדולה אינה נחשבת צפייה.
- נדרשים לפחות 95% מהמקטעים הייחודיים ואירוע סיום כדי להשלים שיעור.
- התקדמות נשמרת כל 10 שניות ובאירועי עצירה. סגירה פתאומית עלולה לאבד את שניות הצפייה האחרונות.
- זהו מנגנון התקדמות לימודי, לא מנגנון השגחה או הוכחת צפייה בלתי ניתנת לזיוף.
- דירוג רשות: תלמיד רשאי לדרג רק אחרי השלמה. עדכון דירוג מחליף את הקודם.
- אין מניעה מצפייה בסרטון המקורי ב־YouTube. מדיניות היוצר והזמינות ב־YouTube קובעות אם ההטמעה תפעל.

## הפורום

הנושאים משויכים לקורסים ובנוסף נושא כללי. תלמיד ומנהל עורכים רק את התוכן שלהם. מנהל רשאי להסיר תוכן של אחרים. הסרת תגובה משאירה סימון כדי לשמור על ההקשר. מחיקת נושא היא ארכוב. אין HTML גולמי בהודעות. תצוגת שרשור מוגבלת ל־300 תגובות ותצוגת נושא ל־100 הודעות בגרסה זו; פגינציה היא הרחבה נדרשת למערכת גדולה.

## תוכן

233 סרטונים זמינים ב־12 רשימות בעברית, שנאספו ב־26.09.2026. שמות הסרטונים, הסדר והמשך נלקחו מ־YouTube. בקורס Bootstrap הושמט סרטון פרסום מנוי; יתר הסדר נשמר. קורס Python משתמש ברשימה שהמשתמש צירף.

תכני CRM מתמקדים ב־Fireberry; ERP בסדרת ממשק משתמש רשמית של Priority. MongoDB ו־Data Analyst הם קורסי מבוא. חלק מהתכנים ותיקים, ולכן יש להתייחס לגרסאות הכלים המוצגות בסרטון. רשימות המקור והקרדיטים מופיעים במסך ״אודות ומקורות״ ובקורסים.

אין התחייבות לזמינות עתידית של כל סרטון. לא הורדנו וידאו ולא העלינו תוכן מחדש.
